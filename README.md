# Mian Ali Traders — Medical Store POS & Inventory System

Point of sale, inventory, and reporting system for Mian Ali Traders medical stores in Talwandi and Kasur.

## Tech Stack
- **Frontend**: React 19, TanStack Start / React Router, Tailwind CSS
- **Database & Auth**: Supabase
- **Hosting**: Cloudflare Pages / Workers
